# Sound Effects

This folder contains audio files for the game.

## Required Sound Files

Place the following sound files in this directory:

- `correct.mp3` - Sound when a correct answer is revealed
- `wrong.mp3` - Sound when a strike is added (buzzer sound)
- `applause.mp3` - Sound for winning/banking points
- `theme.mp3` - Optional background music

## Sound File Format

- Format: MP3 or WAV
- Recommended: MP3 for smaller file size
- Keep files under 500KB each for fast loading

## Finding Sounds

You can find free sound effects at:
- [Freesound.org](https://freesound.org/)
- [Zapsplat.com](https://www.zapsplat.com/)
- [SoundBible.com](http://soundbible.com/)

## Usage in Code

Sounds are played using the browser's Web Audio API in the game components.
